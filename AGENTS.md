# AGENTS.md

## Project-specific instructions for AI agents

- **NEVER save scratch work, scripts, or temp files in throwaway locations**
  (`/tmp`, `/tmp/opencode`, `$env:TEMP`, or any temp folder). All work must
  live inside this repository (e.g. `C:\proj\v1OJPH`), so it is tracked and
  reusable. If temporary analysis is needed, keep it under a tracked
  directory in the repo (e.g. `scratch/`).
